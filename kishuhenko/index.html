STEP
1古いスマホでバックアップ約15分

データが消えないように、古いスマホで「保存（バックアップ）」をしておきます。Wi-Fiにつないでから始めてください。

1写真のバックアップを確認 古いスマホ

  1. フォト アプリを開きます。
  2. 右上の 丸いアイコン（自分の写真や頭文字） をタップします。
  3. 「バックアップ完了」 と出ていればOKです。

「バックアップをオンにする」と出たら、それをタップしてください。完了するまでWi-Fiにつないだまま待ちます（写真が多いと数時間かかることがあります）。

2LINEのトークを保存 古いスマホ

  1. LINE を開き、下の ホーム をタップします。
  2. 右上の ⚙ 設定 → トークのバックアップ をタップします。
  3. 今すぐバックアップ をタップします。
  4. 「PINコード」を求められたら、一覧表に書いてある6けたの数字 を入力します。

「前回のバックアップ：今日の日付」になればOKです。

3＋メッセージを保存 古いスマホ

  1. ＋メッセージ を開き、右下の マイページ をタップします。
  2. 設定 → メッセージ → バックアップ・復元 をタップします。
  3. バックアップ をタップし、保存先は Googleドライブ を選びます。

※ 表示される言葉が少し違うことがあります。似たボタンを選んでください。

STEP
2データを新しいスマホへ移す約30〜60分

「Smart Switch（スマートスイッチ）」という機能で、電話帳・写真・アプリなどをまとめて移します。2台を近くに置き、充電器につないだまま 行ってください。

1新しいスマホの電源を入れる 新しいスマホ

  1. 右側面の 電源ボタンを長押し します（画面がつくまで）。
  2. 「日本語」になっていることを確認して 開始 をタップ。
  3. 同意の画面が出たら、内容を確認して 同意する → 次へ。
  4. Wi-Fiの画面で 事業所のWi-Fi を選び、一覧表のパスワードを入力します。

2「データをコピー」を選ぶ 新しいスマホ

  1. 「アプリとデータをコピー」の画面で 次へ をタップ。
  2. 「古い端末の種類」は Galaxy / Android を選びます。
  3. 「古い端末の Smart Switch を開いてください」と出たら、そのまま置いておきます。

3古いスマホで送信を始める 古いスマホ

  1. 設定（歯車のアイコン）を開きます。
  2. アカウントとバックアップ → Smart Switch をタップ。
  3. データを送信 → ワイヤレス をタップ。
  4. 新しいスマホにつながると「許可しますか？」と出るので 許可 をタップ。

Smart Switch の更新を求められたら 更新 をタップしてください。

4移すデータを選んで転送 新しいスマホ

  1. Googleアカウントのログインを求められたら、一覧表のメールアドレスとパスワード を入力します。
  2. 「コピーするデータ」は 全部にチェック が入っていることを確認します。
  3. コピー（または 転送）をタップします。
  4. 終わるまで待ちます。途中で画面を閉じたり、2台を離したりしないでください。
  5. 「完了」と出たら 次へ。その後の設定は画面の案内に従って進めます。

古いスマホに「ログインしようとしていますか？」と出たら はい をタップしてください。

📝 画面ロック（暗証番号）の設定について

途中で「画面ロック」を求められたら、一覧表に書いてある番号 を設定してください。

STEP
3SIMカードを入れかえる約5分

電話番号が入っている小さなカード（SIMカード）を新しいスマホへ移します。

📝 本社から新しいSIMカードが届いている場合

古いスマホのSIMではなく、届いた新しいSIMカード を新しいスマホに入れてください。

12台とも電源を切る 2台とも

電源ボタンを長押し → 電源OFF をタップ。

2SIMカードを取り出して入れる 2台とも

  1. スマホの側面にある 小さな穴 に、SIMピンをまっすぐ差し込むと、トレイが出てきます。
  2. 古いスマホのSIMカードを取り出し、同じ向き で新しいスマホのトレイにのせます（角が欠けている向きを合わせます）。
  3. トレイをまっすぐ奥まで戻します。

SIMカードの金色の部分にはさわらないでください。小さいので落とさないよう、机の上で作業してください。

3新しいスマホの電源を入れて確認 新しいスマホ

  1. 画面の右上にアンテナのマーク 📶 が出るまで待ちます（1〜2分）。
  2. 同僚などに 電話をかけて、つながることを確認します。

STEP
4LINEを引き継ぐ約10分

LINEだけは別の手順が必要です。古いスマホに出る「QRコード」を新しいスマホで読み取ります。
（古いスマホはSIMが無くてもWi-Fiで動きます）

1新しいスマホでLINEを開く 新しいスマホ

  1. LINE アプリを開きます。
    （見つからない場合は Playストア で「LINE」とさがしてインストール）
  2. ログイン → QRコードでログイン → QRコードをスキャン をタップ。
  3. カメラの画面になったら、そのまま次へ進みます。

2古いスマホでQRコードを出す 古いスマホ

  1. LINE → ホーム → 右上の ⚙ 設定 をタップ。
  2. かんたん引き継ぎQRコード をタップします。
  3. QRコードが表示されます。

3QRコードを読み取る 2台とも

  1. 新しいスマホ のカメラを、古いスマホのQRコードに向けます。
  2. 古いスマホ に「新しい端末でこのアカウントにログインしますか？」と出たら 次へ をタップし、画面ロックを解除します。

4トーク履歴を戻す 新しいスマホ

  1. トーク履歴を復元 をタップします。
  2. 一覧表のPINコード（6けた） を入力します。
  3. 友だちやトークが表示されれば完了です。

引き継ぎが終わると、古いスマホのLINEは使えなくなります。これは正常です。

STEP
5最後のチェック約10分

新しいスマホで、ひとつずつアプリを開いて確認します。全部チェックが付いたら完了です。

1＋メッセージを開く 新しいスマホ

  1. ＋メッセージ を開き、案内に沿って 次へ・許可 をタップします。
  2. 前のメッセージが無い場合は マイページ → 設定 → メッセージ → バックアップ・復元 → 復元 をタップします。

2そのほかのアプリを確認 新しいスマホ

  • 電話 → 連絡先：いつも使う人の名前があるか
  • Gmail：受信メールが見られるか
  • フォト：前の写真が見られるか（表示まで少し時間がかかることがあります）

✅ 完了チェックリスト

🎉 おつかれさまでした
  • 古いスマホは 初期化せず、電源を切って本社の指示どおりに返却してください。
  • 完了したら、本社 情報システム担当へ「機種変更が終わりました」と連絡してください。

？困ったとき

Smart Switch が途中で止まった・つながらない

2台をくっつけるくらい近くに置き、両方の画面をつけたままにしてください。それでもだめなら、2台とも再起動して STEP 2 の③からやり直してください。

Googleのログインで「確認コード」や「本人確認」を求められた

古いスマホに確認の通知が来ていないか見てください（はい をタップ）。来ていない場合は本社へ連絡してください。

LINEのPINコードが違うと言われた

一覧表の数字をもう一度確認してください。何度も試さずに、2回まちがえたら本社へ連絡してください。

電話がつながらない（圏外のまま）

新しいスマホを再起動してください。直らない場合は、SIMカードの向きを確認して入れ直してください。

電話帳の数が足りない

古いスマホは消さずに本社へ連絡してください。本社で移し直します。
