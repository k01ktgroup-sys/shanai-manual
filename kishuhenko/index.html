スマホ機種変更マニュアル

古いスマホ（SCV46）から新しいスマホ（Galaxy A25 5G）へ、データを引き継ぐ手順です。
上から順番に進めてください。

STEP
1古いスマホでバックアップ約15分

データが消えないように、古いスマホで「保存（バックアップ）」をしておきます。まずWi-Fiにつなぎます。

1Wi-Fiにつなぐ 古いスマホ

  1. 設定（歯車のアイコン）を開きます。
  2. 接続 → Wi-Fi をタップします。
  3. 右上のスイッチが オン（青色） になっていなければ、タップしてオンにします。
  4. 一覧の中から 一覧表に書いてある事業所のWi-Fiの名前 をタップします。
  5. 一覧表のWi-Fiのパスワードを入力して 接続 をタップします。

Wi-Fiの名前の下に 「接続済み」 と出ればOKです。

パスワードは大文字・小文字の区別があります。入力欄の横の 目のマーク をタップすると、入力した文字を確認できます。

2写真のバックアップを確認 古いスマホ

  1. フォト アプリを開きます。
  2. 右上の 丸いアイコン（自分の写真や頭文字） をタップします。
  3. 「バックアップ完了」 と出ていればOKです。

「バックアップをオンにする」と出たら、それをタップしてください。完了するまでWi-Fiにつないだまま待ちます（写真が多いと数時間かかることがあります）。

3LINEのトークを保存 古いスマホ

  1. LINE を開き、下の ホーム をタップします。
  2. 右上の ⚙ 設定 → トークのバックアップ をタップします。
  3. 今すぐバックアップ をタップします。
  4. 「PINコード」を求められたら、一覧表に書いてある6けたの数字 を入力します。

「前回のバックアップ：今日の日付」になればOKです。

「アカウント引き継ぎ」の設定は？

設定画面に「アカウント引き継ぎ」のスイッチがあっても、さわらなくて大丈夫です。今回は STEP 4 の「QRコード」で引き継ぐので、このスイッチは使いません。

4＋メッセージを保存 古いスマホ

  1. ＋メッセージ を開き、右下の マイページ をタップします。
  2. 設定 → メッセージ → バックアップ・復元 をタップします。
  3. バックアップ をタップし、保存先は Googleドライブ を選びます。

※ 表示される言葉が少し違うことがあります。似たボタンを選んでください。

STEP
2新しいスマホにSIMカードを入れる約10分

電話番号が入っている小さなカード（SIMカード）を、古いスマホから新しいスマホへ入れかえます。机の上で 作業してください。

📝 本社から新しいSIMカードが届いている場合

手順 2 はとばして、届いた新しいSIMカード を新しいスマホに入れてください。

1SIMピンを取り出す 新しいスマホの箱

  1. 新しいスマホの箱を開けます。
  2. 本体の下に入っている 小さな箱 を取り出します。
  3. 小さな箱を 裏返す と、SIMピン（細い針のような金具）が付いています。

SIMピンは先がとがっています。取り扱いに注意してください。

2古いスマホからSIMカードを取り出す 古いスマホ

  1. 電源ボタンを長押し → 電源OFF をタップして、電源を切ります。
  2. 本体の側面にある 小さな穴 に、SIMピンをまっすぐ差し込みます。トレイ（SIMカードをのせる台）が少し出てきます。
  3. トレイを指で引き出し、SIMカードを取り出します。
  4. 空になったトレイを元に戻し、古いスマホの電源をもう一度入れます（このあとWi-Fiで使います）。

古いスマホに「SIMカードがありません」と出ますが、正常です。

3新しいスマホのトレイを出す 新しいスマホ

  1. 新しいスマホの 画面を自分のほうに向けて 持ちます。
  2. 本体の 左上 にある小さな穴に、SIMピンを まっすぐ 差し込み、少し強めに押します。
  3. トレイが少し出てきたら、指でつまんで引き出します。

4SIMカードをのせて戻す 新しいスマホ

  1. SIMカードの 金色の面を下 にします。
  2. SIMカードの 角が欠けているところ を、トレイのくぼみの形に合わせてのせます。
  3. SIMカードが落ちないようにトレイを水平にしたまま、まっすぐ奥まで 押し込みます。

金色の部分には指でさわらないでください。

入りにくいときは無理に押し込まず、一度出して向きを確かめてください。

5電源を入れる 新しいスマホ

  1. 右側面の 下側のボタン（音量ボタンの下）を、画面が明るくなるまで長押し します（約3秒）。
  2. 「Samsung Galaxy」の文字が出たら指を離します。
  3. 「ようこそ」の画面が出るまで待ちます（1分くらい）。出たら STEP 3 へ進みます。

上側の長いボタンは音量ボタンです。まちがえないようにしてください。

STEP
3データを新しいスマホへ移す約30〜60分

「Smart Switch（スマートスイッチ）」という機能で、電話帳・写真・アプリなどをまとめて移します。2台を近くに置き、充電器につないだまま 行ってください。

1最初の設定をする 新しいスマホ

  1. 「日本語」になっていることを確認して 開始 をタップ。
  2. 同意の画面が出たら、内容を確認して 同意する → 次へ。

2「簡単設定」で Galaxy を選ぶ 新しいスマホ

  1. 「別のデバイスを使用して簡単設定」という画面が出ます。
  2. GalaxyまたはAndroidデバイス をタップします。
  3. このあとは画面の案内に従って進めます。Wi-Fiを求められたら 事業所のWi-Fi を選び、一覧表のパスワードを入力します。
  4. 「QRコードをスキャンする」という画面になったら、次の③へ進みます。

iPhone または iPad・手動で設定 は選ばないでください。

3QRコードを読み取る 2台とも

  1. 新しいスマホ に「QRコードをスキャンする」とQRコードが出ます。そのまま置いておきます。
  2. 古いスマホ で カメラ アプリを開き、新しいスマホのQRコードに向けます。
  3. 古いスマホの画面に表示（お知らせやリンク）が出たら、それをタップします。
  4. このあとは 古いスマホに出る案内 に従って、次へ・コピー などをタップします。画面ロックの解除を求められたら、古いスマホのロックを解除します。
カメラで読み取れないとき
  • QRコード全体が画面に入るように、少し離したり近づけたりしてください。
  • それでも読み取れない場合は、古いスマホの Google アプリを開き、検索欄の右にある カメラのマーク をタップしてQRコードに向けてください。

新しいスマホの スキップ はタップしないでください。

4古いスマホで Smart Switch を開く 古いスマホ

※ ③のあと、古いスマホで Smart Switch が自動で開いた場合や、「データを送信」の画面が出た場合は ⑤ へ進みます。

  1. 設定（歯車のアイコン）を開きます。
  2. アカウントとバックアップ → Smart Switch をタップ。
  3. 2つの選択肢のうち、古いデバイスからデータを移行 をタップします。
  4. 「Smart Switch をダウンロードしますか？」と出たら ダウンロード（または インストール）をタップします。
  5. ダウンロードが終わると Smart Switch が開きます。開かないときは 開く をタップします。

古いスマホで操作していても、「古いデバイスからデータを移行」で正しい です。「外部ストレージ転送」は選ばないでください。

ダウンロードについて
  • Wi-Fiにつながっていることを確認してから行ってください（数分かかります）。
  • 「更新」と出た場合も、同じように 更新 をタップしてください。
  • 「Samsungアカウント」のログインを求められて進めない場合は、いったん戻り、Playストア で「Smart Switch」とさがして インストール（または 更新）してください。

5古いスマホで送信を始める 古いスマホ

  1. データを送信 をタップします。
  2. つなぎ方は ワイヤレス をタップします。
  3. 新しいスマホにつながると「許可しますか？」と出るので 許可 をタップします。

データを受信 はまちがいです。必ず 「送信」 を選んでください。

6移すデータを選んで転送 新しいスマホ

  1. Googleアカウントのログインを求められたら、一覧表のメールアドレスとパスワード を入力します。
  2. 「コピーするデータ」は 全部にチェック が入っていることを確認します。
  3. コピー（または 転送）をタップします。
  4. 終わるまで待ちます。途中で画面を閉じたり、2台を離したりしないでください。
  5. 「完了」と出たら 次へ。その後の設定は画面の案内に従って進めます。

古いスマホに「ログインしようとしていますか？」と出たら はい をタップしてください。

📝 画面ロック（暗証番号）の設定について

途中で「画面ロック」を求められたら、一覧表に書いてある番号 を設定してください。

STEP
4LINEを引き継ぐ約10分

LINEだけは別の手順が必要です。古いスマホに出る「QRコード」を新しいスマホで読み取ります。
（古いスマホはSIMが無くてもWi-Fiで動きます）

1新しいスマホでLINEを開く 新しいスマホ

  1. LINE アプリを開きます。
    （見つからない場合は Playストア で「LINE」とさがしてインストール）
  2. ログイン → QRコードでログイン → QRコードをスキャン をタップ。
  3. カメラの画面になったら、そのまま次へ進みます。

2古いスマホでQRコードを出す 古いスマホ

  1. LINE → ホーム → 右上の ⚙ 設定 をタップ。
  2. かんたん引き継ぎQRコード をタップします。
  3. QRコードが表示されます。

3QRコードを読み取る 2台とも

  1. 新しいスマホ のカメラを、古いスマホのQRコードに向けます。
  2. 古いスマホ に「新しい端末でこのアカウントにログインしますか？」と出たら 次へ をタップし、画面ロックを解除します。

4トーク履歴を戻す 新しいスマホ

  1. トーク履歴を復元 をタップします。
  2. 一覧表のPINコード（6けた） を入力します。
  3. 友だちやトークが表示されれば完了です。

引き継ぎが終わると、古いスマホのLINEは使えなくなります。これは正常です。

STEP
5最後のチェック約10分

新しいスマホで、ひとつずつアプリを開いて確認します。全部チェックが付いたら完了です。

1＋メッセージを開く 新しいスマホ

  1. ＋メッセージ を開き、案内に沿って 次へ・許可 をタップします。
  2. 前のメッセージが無い場合は マイページ → 設定 → メッセージ → バックアップ・復元 → 復元 をタップします。

2そのほかのアプリを確認 新しいスマホ

  • 電話 → 連絡先：いつも使う人の名前があるか
  • Gmail：受信メールが見られるか
  • フォト：前の写真が見られるか（表示まで少し時間がかかることがあります）

✅ 完了チェックリスト

🎉 おつかれさまでした
  • 古いスマホは 初期化せず、電源を切って本社の指示どおりに返却してください。
  • 完了したら、本社 情報システム担当へ「機種変更が終わりました」と連絡してください。

？困ったとき

Smart Switch が途中で止まった・つながらない

2台をくっつけるくらい近くに置き、両方の画面をつけたままにしてください。それでもだめなら、2台とも再起動して STEP 3 の③からやり直してください。

Googleのログインで「確認コード」や「本人確認」を求められた

古いスマホに確認の通知が来ていないか見てください（はい をタップ）。来ていない場合は本社へ連絡してください。

LINEのPINコードが違うと言われた

一覧表の数字をもう一度確認してください。何度も試さずに、2回まちがえたら本社へ連絡してください。

電話がつながらない（圏外のまま）

新しいスマホを再起動してください。直らない場合は、SIMカードの向きを確認して入れ直してください。

電話帳の数が足りない

古いスマホは消さずに本社へ連絡してください。本社で移し直します。
